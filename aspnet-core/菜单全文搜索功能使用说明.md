# 菜单全文搜索功能使用说明

## 功能概述

本系统提供了基于ElasticSearch的菜单全文搜索功能，支持通过关键字快速查找和跳转到对应的菜单页面。

## 主要特性

- ✅ 全文搜索：支持菜单名称、路径、权限码等字段的全文搜索
- ✅ 拼音搜索：支持中文菜单名称的拼音搜索
- ✅ 首字母搜索：支持英文菜单名称的首字母搜索
- ✅ 高亮显示：搜索结果中关键字高亮显示
- ✅ 搜索建议：实时提供搜索建议
- ✅ 分页查询：支持分页显示搜索结果
- ✅ 自动索引：菜单变更时自动同步索引
- ✅ 层级路径：显示菜单的完整层级路径

## API接口

### 1. 搜索菜单

**接口地址：** `POST /api/MenuSearch/search`

**请求参数：**
```json
{
  "keyword": "用户管理",
  "pageIndex": 1,
  "pageSize": 10,
  "onlyVisible": true,
  "parentId": null
}
```

**响应示例：**
```json
{
  "isSuc": true,
  "msg": "操作成功",
  "code": 200,
  "data": {
    "data": [
      {
        "id": "12345678-1234-1234-1234-123456789012",
        "parentId": "87654321-4321-4321-4321-210987654321",
        "menuName": "用户管理",
        "path": "/user/list",
        "component": "views/user/List.vue",
        "icon": "user",
        "permissionCode": "user:list",
        "isVisible": true,
        "sort": 1,
        "parentMenuName": "系统管理",
        "menuPath": "系统管理/用户管理",
        "score": 3.5,
        "highlightedMenuName": "<em>用户</em>管理"
      }
    ],
    "totalCount": 1,
    "pageIndex": 1,
    "pageSize": 10
  }
}
```

### 2. 快速搜索

**接口地址：** `GET /api/MenuSearch/quick-search`

**请求参数：**
- `keyword`: 搜索关键字
- `pageIndex`: 页码（可选，默认1）
- `pageSize`: 页大小（可选，默认10）

**示例：**
```
GET /api/MenuSearch/quick-search?keyword=用户&pageIndex=1&pageSize=10
```

### 3. 获取搜索建议

**接口地址：** `GET /api/MenuSearch/suggestions`

**请求参数：**
- `keyword`: 关键字
- `limit`: 建议数量限制（可选，默认10）

**示例：**
```
GET /api/MenuSearch/suggestions?keyword=用户&limit=5
```

**响应示例：**
```json
{
  "isSuc": true,
  "msg": "操作成功",
  "code": 200,
  "data": [
    "用户管理",
    "用户列表",
    "用户详情",
    "用户权限",
    "用户角色"
  ]
}
```

### 4. 重建索引

**接口地址：** `POST /api/MenuSearch/rebuild-index`

**说明：** 重新从数据库同步所有菜单数据到ElasticSearch索引

### 5. 测试连接

**接口地址：** `GET /api/MenuSearch/test-connection`

**说明：** 测试ElasticSearch连接状态

## 搜索功能详解

### 1. 搜索字段

搜索功能会在以下字段中进行匹配：
- **菜单名称** (menuName) - 权重最高
- **路径** (path) - 中等权重
- **权限码** (permissionCode) - 中等权重
- **组件路径** (component) - 低权重
- **菜单层级路径** (menuPath) - 低权重

### 2. 搜索类型

#### 中文搜索
- 支持菜单名称的全文匹配
- 支持拼音搜索（如输入"yonghu"可以搜索到"用户"）
- 支持模糊匹配

#### 英文搜索
- 支持菜单名称的全文匹配
- 支持首字母搜索（如输入"UM"可以搜索到"User Management"）
- 支持大小写不敏感搜索

### 3. 搜索结果排序

搜索结果按以下规则排序：
1. **匹配度分数** (Score) - 降序
2. **菜单排序** (Sort) - 升序

## 配置说明

### 1. appsettings.json 配置

```json
{
  "ElasticSearch": {
    "Uri": "http://localhost:9200",
    "Index": "crmsystem",
    "Username": "",
    "Password": "",
    "Timeout": 30,
    "EnableSsl": false,
    "NumberOfShards": 1,
    "NumberOfReplicas": 0
  }
}
```

### 2. 配置参数说明

- **Uri**: ElasticSearch服务器地址
- **Index**: 索引名称
- **Username/Password**: 认证信息（可选）
- **Timeout**: 连接超时时间（秒）
- **EnableSsl**: 是否启用SSL
- **NumberOfShards**: 索引分片数
- **NumberOfReplicas**: 索引副本数

## 使用示例

### 1. 前端调用示例

```javascript
// 搜索菜单
async function searchMenus(keyword) {
    const response = await fetch('/api/MenuSearch/search', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Authorization': 'Bearer ' + token
        },
        body: JSON.stringify({
            keyword: keyword,
            pageIndex: 1,
            pageSize: 10,
            onlyVisible: true
        })
    });
    
    return await response.json();
}

// 获取搜索建议
async function getSuggestions(keyword) {
    const response = await fetch(`/api/MenuSearch/suggestions?keyword=${encodeURIComponent(keyword)}&limit=5`, {
        headers: {
            'Authorization': 'Bearer ' + token
        }
    });
    
    return await response.json();
}

// 快速搜索
async function quickSearch(keyword) {
    const response = await fetch(`/api/MenuSearch/quick-search?keyword=${encodeURIComponent(keyword)}`, {
        headers: {
            'Authorization': 'Bearer ' + token
        }
    });
    
    return await response.json();
}
```

### 2. 搜索结果处理

```javascript
// 处理搜索结果
function handleSearchResults(results) {
    results.data.forEach(menu => {
        console.log(`菜单: ${menu.highlightedMenuName}`);
        console.log(`路径: ${menu.path}`);
        console.log(`层级: ${menu.menuPath}`);
        console.log(`匹配度: ${menu.score}`);
        
        // 点击跳转到对应菜单
        if (menu.path) {
            // 使用前端路由跳转
            router.push(menu.path);
        }
    });
}
```

## 部署要求

### 1. ElasticSearch服务

确保ElasticSearch服务正在运行：
```bash
# 启动ElasticSearch
docker run -d --name elasticsearch -p 9200:9200 -p 9300:9300 elasticsearch:7.17.5
```

### 2. 初始化索引

首次使用需要重建索引：
```bash
# 调用重建索引接口
POST /api/MenuSearch/rebuild-index
```

### 3. 监控和维护

- 定期检查ElasticSearch连接状态
- 监控索引大小和性能
- 根据需要调整搜索权重和配置

## 注意事项

1. **索引同步**: 菜单变更时会自动同步到ElasticSearch，如果同步失败不会影响主业务流程
2. **性能优化**: 大量数据时建议调整分片数和副本数
3. **搜索精度**: 可以通过调整搜索权重来优化搜索精度
4. **错误处理**: 搜索失败时会返回详细的错误信息

## 故障排除

### 1. 连接失败

- 检查ElasticSearch服务是否正常运行
- 验证连接配置是否正确
- 检查网络连接和防火墙设置

### 2. 搜索无结果

- 确认索引是否已创建并包含数据
- 检查搜索关键字是否正确
- 验证菜单数据是否已同步到索引

### 3. 性能问题

- 调整索引分片数和副本数
- 优化搜索查询
- 考虑使用缓存机制
